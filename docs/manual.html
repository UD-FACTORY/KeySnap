1. 프로그램 개요 및 특징

KeySnap은 Windows 환경에서 타이핑의 피로를 획기적으로 줄여주는 전역 텍스트 대치(Text Replacement) 전문 유틸리티입니다. 카카오톡, 슬랙, 노션, 웹 브라우저(크롬/엣지), 워드, 메모장 등 사용자가 작업 중인 모든 응용 프로그램에서 지정한 단축어를 입력한 후 단축키를 누르면 즉각 대치어로 자동 변환됩니다.

주요 핵심 특징

⚡ 모든 Windows 응용 프로그램과의 100% 호환성

저수준 키보드 훅(Low-Level Keyboard Hook) 엔진을 탑재하여 어떤 창이 활성화되어 있든 시스템 전역에서 정확하게 키 입력을 감지합니다.

🇰🇷 강력한 한글 두벌식 초성/자모 분해 엔진

영문 타자 모드나 한글 조합 상태를 신경 쓸 필요 없이, 자판 그대로 ㅇㅈ을 치면 인정합니다. 👍로 완벽하게 자동 변환됩니다.

⌨️ 사용자 맞춤형 임의 단축키 (트리거 키) 녹화

단축어 입력 후 치환을 실행할 단축키를 Tab, Space, Ctrl+Space, Alt+Q 등 원하는 키보드 조합으로 직접 눌러 자유롭게 지정할 수 있습니다.

🛡️ 안전한 클립보드 복원 파이프라인

텍스트를 주입할 때 사용자가 직전에 복사해 둔 클립보드 내용을 손상시키지 않도록 임시 백업 후 수십 밀리초 내로 원상 복원합니다.

🏷️ 실시간 동적 매크로 태그

대치어에 오늘 날짜({{today}}), 현재 시각({{time}}), 클립보드 내용({{clipboard}})을 삽입하여 스마트하게 작성할 수 있습니다.

시스템 트레이 상주 및 자동 실행

  • 백그라운드 구동: 프로그램 우측 상단의 닫기(X) 버튼을 누르면 작업 표시줄 우측 하단의 시스템 트레이(알림 영역)로 조용히 숨겨집니다.
  • 설정 창 다시 열기: 트레이의 보라색 키보드 문서 아이콘을 더블클릭하면 즉시 창이 열립니다.
  • 원클릭 On/Off 토글: 트레이 아이콘을 우클릭하여 [텍스트 대치 사용] 체크박스를 원클릭으로 켜고 끌 수 있습니다.

3. 텍스트 대치 및 단축어 관리

KeySnap의 가장 핵심적인 기능은 등록된 단축어를 감지하여 긴 문장이나 서식 텍스트로 즉각 변환하는 것입니다. 카카오톡, 슬랙, 웹 브라우저, 워드 등 사용자가 작업 중인 모든 응용 프로그램에서 손쉽게 활용할 수 있습니다.

단축어 작동 원리

  1. 문서 작성기, 메신저, 웹 폼 등에서 등록된 단축어(예: ㅇㅈ 또는 !email)를 타이핑합니다.
  2. 설정된 치환 실행 단축키(기본값: Tab)를 누릅니다.
  3. 직전에 입력된 단축어가 자동으로 지워지며, 미리 설정된 긴 대치 문구로 눈 깜짝할 사이에 치환됩니다!
▲ [그림 1] KeySnap 단축어 관리 및 등록 목록 화면

단축어 추가 및 관리 방법

1) 새 단축어 추가

메인 창 좌측의 [단축어 관리] 탭에서 우측 상단의 [+ 단축어 추가] 버튼을 클릭합니다. 대화상자에 사용할 단축어와 변경될 대치 문구를 입력하고 저장합니다.

2) 수정 및 삭제

목록에서 수정하려는 항목의 [수정] 버튼을 누르거나 더블클릭하여 내용을 편집할 수 있으며, 불필요한 단축어는 [삭제] 버튼으로 언제든 제거할 수 있습니다.

3) 개별 사용/중지 스위치

자주 쓰지 않는 단축어는 삭제할 필요 없이 목록 좌측의 상태 토글 스위치를 클릭하여 즉시 비활성화할 수 있습니다.

💡 한글 초성/자모 단축어 팁:
한/영 전환 키를 누를 필요 없이 자판 그대로 ㅇㅈ, ㄱㅅ, ㅈㄱ 등을 입력하면 영문 타자 버퍼(dw, rt, wr)를 지능적으로 분석하여 한글 단축어로 자동 매칭합니다.

기본 등록 단축어 예시

단축어 대치 문구 변환 방식 그룹
ㅇㅈ 인정합니다. 👍 즉시 변환 일상
ㄱㅅ 감사합니다! 좋은 하루 보내세요.... 😊 즉시 변환 인사
ㅈㄱ 지금 통화 가능하신가요? 즉시 변환 업무
!email user@example.com 즉시 변환 개인정보
!date {{today}} (현재 오늘 날짜 자동 입력) 즉시 변환 매크로
!time {{time}} (현재 시각 자동 입력) 즉시 변환 매크로
btw by the way 트리거 키 (Space/Enter) 영어

4. 치환 실행 단축키 (트리거 키) 설정

KeySnap은 사용자의 타이핑 습관에 맞추어 원하는 임의의 키보드 단축키를 직접 누르면 즉시 감지되어 적용되는 대화형 키 녹화 기능을 제공합니다.

▲ [그림 2] KeySnap 환경설정 및 치환 실행 단축키 설정 화면

단축키 변경 방법

  1. 좌측 사이드바에서 [환경설정] 메뉴를 클릭합니다.
  2. '⚡ 치환 실행 단축키 및 클립보드' 섹션에서 ⌨ 단축키 변경 버튼을 누릅니다.
  3. 화면에 🔴 원하는 키 또는 조합키를 누르세요... (취소: ESC) 알림이 나타납니다.
  4. 키보드에서 원하는 키(예: Tab, Space, Ctrl+Space, Shift+Space, Alt+Q, F8 등)를 누르면 즉각 감지되어 저장됩니다.
  5. 언제든 기본값 (Tab) 버튼을 눌러 초기 상태로 손쉽게 되돌릴 수 있습니다.
💡 Tab 키 스마트 가로채기:
Tab 키를 단축키로 사용할 경우, 치환이 일어날 때 탭 키 입력을 가로채어 입력창에서 포커스가 다음 버튼이나 필드로 튀는 현상을 원천 방지합니다.

5. 예외 프로그램 관리 (블랙리스트)

게임 플레이 중이거나 은행/증권 보안 프로그램, 또는 단축키 간섭이 발생할 수 있는 특정 프로그램에서는 텍스트 대치가 동작하지 않도록 예외 프로그램 목록을 관리할 수 있습니다.

▲ [그림 3] KeySnap 예외 프로그램 관리 화면

예외 프로그램 등록 방법

  • 실행 중인 창에서 선택 (가장 편리):
    우측 상단의 [+ 프로그램 추가]를 누르면 현재 컴퓨터에서 켜져 있는 창 목록이 표시되며, 원하는 프로그램을 클릭 한 번으로 간편하게 등록할 수 있습니다.
  • 파일 찾아보기 (.exe):
    실행 파일 경로를 직접 선택하여 등록하고 싶을 때는 [파일 찾아보기(.exe)] 버튼을 사용합니다.
  • 기본 프리셋 제공:
    리그 오브 레전드(League of Legends), 오버워치(Overwatch), 발로란트(Valorant) 등 대표적인 게임들이 기본 예외 프로그램으로 탑재되어 있습니다.

7. 데이터 백업 및 복원

새로운 PC로 컴퓨터를 교체하거나 다른 동료와 단축어 목록을 공유하고 싶을 때, 단 한 번의 클릭으로 데이터를 내보내고 가져올 수 있습니다.

  • 내보내기: [단축어 관리] ➔ [내보내기] 클릭 ➔ JSON 파일로 안전하게 저장
  • 가져오기: [단축어 관리] ➔ [가져오기] 클릭 ➔ 백업한 JSON 파일을 선택하여 복원

8. 문제 해결 및 FAQ

Q1. 설치 파일을 실행했을 때 Windows의 PC 보호(SmartScreen) 알림이 뜹니다.

KeySnap은 안전한 오픈소스 소프트웨어입니다. 신규 배포 프로그램의 경우 마이크로소프트의 누적 다운로드 평판이 쌓이기 전까지 SmartScreen 경고 창이 나타날 수 있습니다.
화면 중앙의 [추가 정보] 링크를 클릭한 후, 활성화되는 [실행] 버튼을 누르시면 정상적으로 설치가 진행됩니다.

Q2. 단축어를 입력했는데 대치가 일어나지 않습니다.
  1. 좌측 사이드바 하단의 [전역 텍스트 대치] 마스터 스위치가 켜져 있는지 확인합니다.
  2. [환경설정]에서 설정된 치환 실행 단축키(예: Tab 또는 Space)를 정확히 눌렀는지 확인합니다.
  3. 현재 사용 중인 프로그램이 [예외 프로그램 관리] 목록에 등록되어 있는지 확인합니다.
Q3. 대치 후 이전 클립보드 복사 내용이 사라지지 않나요?

KeySnap은 치환 직전 사용자의 클립보드 내용을 임시 백업한 후, 대치어를 입력하고 기본 80ms(밀리초) 이내에 원래 클립보드로 완벽히 복원합니다. 복원 속도는 [환경설정] 탭의 '클립보드 복원 대기 지연 시간'에서 자유롭게 조절할 수 있습니다.
